Aurora는 마크다운 메모·드로잉·시트·링크 그래프에 로컬 AI 자동화를 더한 오프라인 데스크톱 앱입니다. 계정도 서버도 없고, 메모가 밖으로 나가지 않습니다. 글은 직접 고른 폴더에 실제 파일로 저장되고, AI는 내 컴퓨터에서 도는 Ollama 모델이 처리합니다.

Windows 10 이상 · macOS 11 이상 v7.0.2 내려받은 뒤 압축을 풀어 설치합니다

  • 메모는 파일이다. 고른 폴더에 마크다운·드로잉·시트가 그대로 쌓입니다. 앱을 지워도 글은 남습니다.
  • AI는 내 컴퓨터에서 돈다. 로컬 Ollama 모델로 요약·번역·태깅·정리를 합니다. 외부 API를 부르지 않습니다.
  • 반복은 플로우가 한다. 트리거 → AI 처리 → 파일 작업을 노드로 잇고, 원할 때 예약해 둡니다.
  • 연결이 보인다. 위키링크·태그 관계를 2D/3D 그래프로 확인합니다.

내 파일, 내 컴퓨터

Aurora는 시작할 때 저장 폴더를 한 번 묻고, 그 뒤로는 그 폴더 안에서만 움직입니다. 메모 하나는 데이터베이스 행이 아니라 .md 파일 한 개입니다. 탐색기에서 열어도, 다른 편집기로 열어도, 10년 뒤에 열어도 같은 글입니다.

내 메모를 아는 AI, 내 컴퓨터 안에서

채팅은 Ollama에 설치된 로컬 모델로 돌아갑니다. 지식베이스는 AI가 읽을 범위, 프로젝트는 AI가 파일을 쓸 수 있는 범위로 따로 정합니다. 비밀번호로 잠근 메모는 읽기 범위에서 빠지고, 파일을 만들거나 덮어쓰는 작업은 승인을 거칩니다 — 프로젝트 폴더 안이라면 “이 폴더 항상 허용”을 골라 둘 수 있고, 폴더 밖 경로는 항상 허용할 수 없습니다.

  • Aurora-7.0.2-win.zip을 내려받아 압축을 풀고, 안에 있는 설치 파일(.exe)을 실행합니다.

macOS

  • Aurora-7.0.2-mac.dmg.zip의 압축을 풀면 .dmg 파일이 나옵니다. 열어서 Aurora를 응용 프로그램 폴더로 끌어 놓습니다.
  • 서명·공증을 하지 않은 빌드라 그냥 열면 “확인되지 않은 개발자” 경고가 납니다. Finder에서 Aurora를 우클릭 → 열기 → 열기로 한 번만 실행해 주세요.
  • 첫 실행에서 저장 폴더를 지정합니다.

AI 기능을 쓰려면 (선택)

  • AI 채팅과 플로우의 AI 노드는 로컬 Ollama가 필요합니다. Ollama를 설치한 뒤 앱의 AI 모델 다운로드에서 대화 모델을 받으세요.
  • 지식베이스(RAG)를 쓰려면 임베딩 모델 nomic-embed-text도 함께 받습니다.
  • 모델을 내려받을 때만 네트워크를 쓰고, 그 뒤 추론은 전부 내 컴퓨터에서 실행됩니다.
  • AI를 쓰지 않아도 메모·드로잉·시트·그래프·검색은 모두 그대로 동작합니다.

자주 묻는 질문

인터넷이 꼭 필요한가요?

아니요. 메모·드로잉·시트·검색·그래프는 모두 오프라인에서 동작합니다. 네트워크가 필요한 순간은 Ollama 모델을 내려받을 때뿐입니다.

내가 쓴 글이 어디론가 전송되나요?

전송되지 않습니다. 계정도, 서버도, 사용 기록 수집도 없습니다. AI 추론까지 내 컴퓨터의 Ollama에서 실행되므로 메모가 외부 API로 나가지 않습니다.

메모는 어떤 형식으로 저장되나요?

고른 폴더 안의 실제 파일입니다. 메모는 마크다운, 드로잉은 Excalidraw 장면, 시트는 시트 파일로 저장됩니다. 다른 편집기로 열어도 되고, 폴더째 복사하면 그게 곧 백업입니다.

AI를 안 쓰면 반쪽짜리인가요?

아닙니다. Ollama를 설치하지 않으면 AI 채팅과 플로우의 AI 노드만 쓸 수 없고, 나머지 기능은 전부 그대로입니다.

비밀번호 잠금은 파일을 암호화하나요?

아니요. 앱 안에서 내용을 감추고 접근을 막는 기능이며, 디스크에 있는 파일 자체를 암호화하지는 않습니다. 잠긴 메모는 검색 결과와 AI 지식베이스에서 제외됩니다.

자동 업데이트가 되나요?

아직 없습니다. 새 버전이 나오면 이 페이지에서 설치 파일을 받아 다시 설치하면 됩니다. 메모는 워크스페이스 폴더에 있으므로 재설치해도 그대로입니다.

백업과 복원은 어떻게 하나요?

설정 → 백업에서 메모·메타정보·템플릿·모델 프로필·플로우를 JSON 한 파일로 내보내고, 같은 화면에서 가져옵니다. 가져온 예약 플로우는 안전을 위해 꺼진 상태로 들어옵니다.
